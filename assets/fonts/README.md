# Fonts for share-card images

Lora (500, 500 italic) and Inter (400, 600), Latin and Latin Extended subsets,
as WOFF from Google Fonts. Both are under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with software.
Used by `lib/family-card.tsx` (next/og needs font files; it can't use
next/font).
